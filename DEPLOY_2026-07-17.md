# Voice Reader — Deploy Steps (2026-07-17 build)

## What changed in this build
- **Speechify provider added** (backend + frontend) with **real word-sync highlighting** via speech marks — no more estimated timing on premium voices.
- **Chunked playback engine**: full-book texts are split at paragraph boundaries (~3.8k chars/chunk), next chunk prefetches while the current one plays, so a 68k-word manuscript streams continuously.
- **Cloud pause/resume fixed** (pausing premium audio previously did nothing).
- **Init bug fixed**: `loadStaticVoices` was called but never defined — the deployed app was dead on load (no buttons worked). This alone is worth deploying.
- **Writer's Desk** (the new purpose of this app):
  - **📝 Note (or press N)** — pauses instantly, shows the passage being read, saves your edit note with its position. Never lose your place.
  - **⧉ Copy passage (or press C)** — current sentence to clipboard.
  - **Resume at N%** — position remembered per document, across sessions.
  - **Export notes** — downloads all notes as a dated Markdown file (passage + note + % position) ready to drop into Jonathan HQ as the next edit spec.
  - Click any saved note to jump back to that spot; Space = play/pause.

## One-time setup
1. Sign up at the Speechify API console (platform.speechify.ai) — Starter plan, $10/mo, ~1M chars included (~2.3 full Book One listens per month; overage $10 per 1M).
2. Copy your API key.
3. Netlify → Site settings → Environment variables → add `SPEECHIFY_API_KEY` = your key.
4. Redeploy (push the 4 files; Netlify auto-builds).

## First listen
1. Open the site → Provider: **Speechify** → voices load (en-GB male voices sorted to the top; pick your narrator).
2. Paste the Book One listening copy (`2026-07-17_The_Remnant_Rising_Listening_Copy_v1.0.txt`) → Load Text → Play.
3. Press **N** whenever something needs an edit note. Export notes when done.
